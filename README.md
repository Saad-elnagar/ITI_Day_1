# ITI Day 1 — C# Fundamentals

[![Build](https://github.com/Saad-elnagar/ITI_Day_1/actions/workflows/dotnet-build.yml/badge.svg?branch=master)](https://github.com/Saad-elnagar/ITI_Day_1/actions/workflows/dotnet-build.yml)

A small console project containing introductory C# exercises focused on values, references, arithmetic, and expression evaluation.

## Concepts Covered

- Floating-point arithmetic.
- Value-type assignment and independent value copies.
- Reference-type assignment and shared object references.
- Integer division and remainder.
- Prefix and postfix increment behavior.

## Run Locally

```bash
dotnet restore "ITI_Day_1.slnx"
dotnet run --project ITI_Day_1/ITI_Day_1.csproj
```

Some later question examples are currently defined but commented out in `Program.cs`; uncomment or invoke them when practicing their output.

## Learning Goal

Use small, repeatable examples to understand how C# evaluates expressions and how value types differ from reference types.
